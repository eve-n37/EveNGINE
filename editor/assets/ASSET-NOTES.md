# EveNGINE built-in artwork

110 original pixel-art assets (48 tiles and 62 sprites), plus eight four-layer map stamps. Artwork was created for this release; no third-party asset packs are included. Individual transparent PNGs are in `png`; pack contact sheets and the palette-indexed `library.json` are also included.

Tiles are 16 × 16; sprite sizes are 16 × 16 through 64 × 64. The pack contact sheets use 64 × 80 slots for browsing, not uniform 16 × 16 tile-sheet import. Use individual PNGs, the built-in editor library or the JSON metadata. Editing imported assets does not change the built-in originals.

The source generator uses Pillow only for rebuilding the artwork; the editor and game require no Python.
